**Project Proposal in CC 116 \- ADVANCED WEB SYSTEMS AND TECHNOLOGIES**

**Project Title:**	

**GadgetWise: Student-Centered Gadget Comparison and Recommendation System** 

**Project Objectives**

 	***General:*** To be able to develop a web application GadgetWise that helps students compare gadgets and choose suitable products based on their budget, academic needs, specifications, durability, and long-term value.   
              	           
 	***Specific:***

1. To enable users to create and manage accounts.  
2. To provide a list of gadget categories such as smartphones, laptops, tablets, headphones, power banks, and smartwatches.  
3. To allow users to search and view detailed gadget information.  
4. To enable users to compare two or more gadgets based on price, specifications, battery life, durability, warranty, and repairability.  
5. To provide personalized gadget recommendations based on the user’s budget and intended academic purpose.  
6. To allow users to submit ratings, reviews, and common gadget issues.  
7. To calculate the estimated monthly ownership cost of each gadget.  
8. To integrate a free external product API on the server side to assist administrators in retrieving basic gadget information (such as name, brand, category, and image) when adding or updating gadget records.  

**Scope:**

1. Allow users to register, log in, and manage their profiles.  
2. Display gadget information, including brand, model, category, price, specifications, warranty, and estimated lifespan.  
3. Allow users to search, filter, sort, and compare gadgets.  
4. Recommend gadgets based on the user’s budget, preferred features, and academic usage.  
5. Calculate the estimated long-term and monthly cost of owning a gadget.  
6. Allow registered users to submit reviews, ratings, and gadget problems.  
7. Include an administrator dashboard for managing users, gadgets, categories, reviews, and reported issues.  
8. Integrate a free external product API on the server side to help administrators fetch basic product information (name, brand, category, image) when encoding gadgets. The API is used only during admin data entry, is optional, and gadgets can also be added manually. 

**Limitations:**

1. The system will only run as a web-based application.  
2. Gadget prices and availability may change and may not always be updated in real time.  
3. The external product API may not contain complete information for all gadgets, especially those sold only in the Philippines.  
4. The free API has usage limits, so it is used only during admin data entry and not for every user request.  
5. The recommendation results are based only on the information stored in the system and user-provided ratings.  
6. The system will not directly sell gadgets or process actual purchases.  
7. Reviews and product information may require administrator verification to prevent inaccurate or misleading content.  
8. The external product API is accessed only from the server; it is not called directly from the client-side interface.

**Website Features:**

1. User registration and login.  
2. Administrator login.  
3. Browse gadget categories.  
4. Search gadgets by name, brand, or category.  
5. Filter gadgets by price range, category, and features.  
6. View detailed gadget information.  
7. Compare two or more gadgets side by side.  
8. Receive personalized gadget recommendations.  
9. Set budget and intended use (e.g., programming, online classes, design).  
10. View estimated monthly ownership cost.  
11. Submit ratings and reviews for gadgets.  
12. Report common gadget issues.  
13. Save gadgets to a wishlist.  
14. View past reviews and comparisons.  
15. View top-rated and most recommended gadgets.  
16. Manage gadget categories, records, specifications, and images (administrators).  
17. Fetch basic product information from an external product API via a server-side endpoint when adding or updating gadgets, verify and moderate reviews, manage reported issues, and generate reports on popular gadgets and categories (administrators).
