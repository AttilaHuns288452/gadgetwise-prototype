Data Export

Back up the catalog as JSON, restore it, or reset every admin change.

Export catalog

Downloads the full live catalog — categories, gadgets, reviews, and issues — as a single JSON file. Use it as a backup or to move data between machines.

Import catalog

Replaces the current dataset with the contents of a previously exported JSON file. The file must contain a gadgets array with at least id and model per record.

Reset admin changes

Clears every admin edit (gadgets, categories, moderation decisions, issue triage, user status) and restores the original sample catalog. Cannot be undone.
